# Mod ideas for this game

Filled automatically from [TefMeister/mod-ideas](https://github.com/TefMeister/mod-ideas) by
`claude-memory/tools/ideas.py`. At the start of every `/pd`, `/lm` or `/ms` session on this game the
session shows `fresh/` as a numbered list; Tefa answers with the numbers to keep.

| Folder | Holds |
| --- | --- |
| `fresh/` | ideas nobody has decided on yet |
| `chosen/` | ideas Tefa picked; they become board rows when work on them starts |
| `done/` | chosen ideas that have been built |
| `decided.md` | one line per decision, so a discarded idea is never offered again |

A discarded idea is deleted here but never lost: Tefa's own words stay in `mod-ideas/inbox/`.
