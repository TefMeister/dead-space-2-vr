# dead-space-2-vr

**Dead Space 2** (2011), a flat-to-VR modding project. Started 2026-09-13.

| Folder | What lives here |
| --- | --- |
| [`dev-archive/`](dev-archive/) | The live mod source, tools, and recon evidence. |
| [`engine-research/`](engine-research/) | The engine dossier: distilled truth about this game's engine, dead ends included. |

The other folders (`mod/` for releases, `modding-notes/` for the dated ledger, `external-research/` for curated public research) are added when there is something to put in them.

Knowledge shared across every project lives in
[flat-to-vr-cross-engine-research](https://github.com/TefMeister/flat-to-vr-cross-engine-research)
and [flat-to-vr-RE-toolkit](https://github.com/TefMeister/flat-to-vr-RE-toolkit);
the account map is [TefMeister/INDEX.json](https://github.com/TefMeister/TefMeister).

This is personal, non-commercial fan modding. Using anything here requires owning a
legitimate copy of the game, and no original game assets are redistributed. See
[`CONTRIBUTING.md`](CONTRIBUTING.md) and [`CREDITS.md`](CREDITS.md) for the full terms
and every source credited.
